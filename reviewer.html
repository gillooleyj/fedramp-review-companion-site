20x Review Companion

Read the claim. Trace the evidence. Explain the judgment.

A reading and note-taking aid for FedRAMP team members. Questions below are suggested review techniques, not new FedRAMP requirements. This prototype does not certify a package or replace the review workbook.

Resume a saved review (optional)

After writing notes, choose Export review notes to save 20x-review-notes.json. On a later visit, reopen the same package files, choose the same class, and load that saved notes file here. This restores your comments and working dispositions; it is not an evidence upload.

Matching uses source filename, content hash, class and JSON pointer. Changed source files do not inherit notes automatically. A loaded note replaces a note for the same source entry.

Files stay in this browser tab. Imported package files are processed in this browser tab and are not uploaded. No automatic saving or remote evidence checks. Export notes before closing. If hashing is unavailable, notes cannot automatically reconnect after reloading a file. Exported notes include filenames, source hashes where available, and your comments; handle them with the package.
